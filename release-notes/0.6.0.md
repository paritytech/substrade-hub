An order that one transaction cannot fill now goes in several, one signature each; Home shows a
Portfolio with each token's value in tUSD; a link opens a market (`#/market/<address>`); and the app
says when the connection to the host drops.

Both networks run new contracts:

- One transaction matches within a budget: 6 local fills, 4 when one leg of each fill settles
  cross-chain, 3 when both do. A limit order the budget stops returns the rest instead of resting it
  across the book.
- The admin role moves in two steps, and the market creation deposit and cross-chain fee are bounded.
- The admin can halt new orders on every market; cancelling, reducing, claiming and withdrawing stay
  open.

**For integrators:** `placeLimitOrder` returns `(orderId, returned)`, listed under the ABI changes
below. `transferAdmin(newAdmin)` keeps its signature but only records `newAdmin` as pending: the role
moves when that account calls `acceptAdmin()`.
