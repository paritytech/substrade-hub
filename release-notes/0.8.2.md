The order form and the release process are hardened after a security review. Trading works as before,
and the contracts are unchanged: both networks keep the 0.8.0 deployment.

- An order sent in several transactions stops if the wallet switches accounts partway through, and
  says which parts went through. Before, later parts were signed by the new account but recorded the
  old one, so they showed in neither account's open orders.
- The amount and price fields accept only a plain number with at most the token's decimals, and say so
  otherwise. Input such as `-0.5` or `1.5.9` was read as a different number.
- "You pay" shows the exact amount an order locks, so a total under one cent no longer reads `0.00`.
- `verify.mjs` checks a release against `networks.json` at its tag, so replaced release files cannot
  make it report a match.
